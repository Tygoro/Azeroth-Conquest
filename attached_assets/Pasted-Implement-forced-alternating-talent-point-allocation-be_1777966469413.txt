Implement forced alternating talent point allocation between class and spec trees.

========================================
POINT GENERATION
========================================

function getAvailablePoints(level: number) {
  return Math.max(0, level - 9);
}

========================================
POINT DISTRIBUTION (CRITICAL)
========================================

Points must alternate between trees.

Rules:

- Level 10 → Class tree
- Level 11 → Spec tree
- Level 12 → Class tree
- Level 13 → Spec tree
- etc

Implement:

function getPointDistribution(level: number) {
  const totalPoints = getAvailablePoints(level);

  let classPoints = 0;
  let specPoints = 0;

  for (let i = 0; i < totalPoints; i++) {
    if (i % 2 === 0) {
      classPoints++;
    } else {
      specPoints++;
    }
  }

  return { classPoints, specPoints };
}

========================================
ENFORCEMENT
========================================

- Player can ONLY allocate:
  - classPoints into class tree
  - specPoints into spec tree

Prevent:
- putting more than allowed into either tree

const ROW_UNLOCKS = {

function isRowUnlocked(rowIndex, treePoints) {

}
